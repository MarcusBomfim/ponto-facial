# Créditos das fotos de teste

Todas são fotos da NASA, em domínio público: obras do governo federal dos Estados Unidos não têm direito autoral lá. Foram reduzidas para no máximo 640 pixels no lado maior. A NASA não endossa este projeto.

Os testes usam pessoas públicas, em retratos oficiais publicados pela própria agência, para não pôr no repositório o rosto de ninguém que não escolheu aparecer.
